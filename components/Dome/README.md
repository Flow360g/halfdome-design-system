# Dome

The standalone half dome, the brand icon, from the uploaded files.

**Props**: `colour` (`"red"` default, `"purple"`, `"gold"`, `"black"`, `"white"`), `size` (width in px, default 64).

Use it for avatars, favicons, sign-offs and as an anchor on covers, sitting on the bottom edge of the frame (`space-0`). Never crop it or turn it upside down.
