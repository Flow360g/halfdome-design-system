# Arrow

A hand-drawn chalk arrow from `assets/Arrows/` to point at a key number or idea.

**Props**: `variant` (1 to 16, default 9, the zig-zag growth arrow), `ink` (`"black"` default or `"white"` on dark grounds), `width` (px, default 120).

Keep arrows black (white on dark). One arrow per view. Don't stretch, rotate past its drawn angle or recolour it.
