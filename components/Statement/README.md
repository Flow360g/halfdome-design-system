# Statement

The values voice: a two or three word line in heavy sans, one brand colour, always ending in a full stop (added automatically).

**Props**: `colour` (`"red"` default, `"purple"`, `"gold"`, `"ink"`). Children: the line, e.g. "Stay classy".

Use for covers, section breaks, posters and social tiles, one per view. Purple and gold statements are display-only; on light grounds they sit below text contrast, so set them at 48px or larger and never for information.
