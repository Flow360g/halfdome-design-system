# Tagline

The vertical "Whole Potential.™" lock-up from the uploaded files.

**Props**: `ink` (`"black"` default or `"white"`), `dome` (`"red"` default, `"purple"`, `"gold"`; white text comes with a red, purple or gold dome), `height` (default 240).

Run it up the edge of a layout with the dome sitting on the edge of the frame. Never set the tagline in live text as a substitute for the lock-up on covers; in running copy write it as **Whole Potential.™**.
