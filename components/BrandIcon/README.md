# BrandIcon

An illustrated brand icon from `assets/Icons/`.

**Props**: `name` (the file stem, e.g. `"Growth"`, `"Handshake"`, `"Search-2"`, `"Social-Media"`), `colour` (`"red"` default, `"purple"`, `"gold"`, `"white"`, some `"black"`), `size` (px, default 64), `label` (accessible name; omit for decorative icons).

Use one colourway per page, matched to the accent. Show at 48px or larger. Not every icon exists in every colour; check the Icons asset group, and the README there lists the full set. Set `HalfDome.config.assetBase` when using the bundle outside this system.
