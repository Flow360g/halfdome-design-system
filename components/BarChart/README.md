# BarChart

A simple grouped bar chart in the brand chart palette.

**Props**: `data` (array of objects with `label` plus one key per series), `series` (array of series keys, in order: `chart-1` sequoia, `chart-2` ink, `chart-3` camas, `chart-4` white fir), `title` (accessible name), `width`, `height`.

Use at most four series; prefer two. Label values directly in the surrounding copy and point at the key bar with an Arrow if needed.
