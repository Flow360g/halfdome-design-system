# Slide

A 1920 x 1080 slide frame that follows the PowerPoint template: `snow` ground, `space-24` margins, headline top left, logo and DD.MM.YY date in the footer.

**Props**
- `layout`: `"content"` (default: headline plus children), `"title"` (large headline with the dome on the bottom edge), `"statement"` (one values-style line), `"quote"` (pull quote with `by`).
- `title`, `subtitle`, `by`, `date` (DD.MM.YY), `accent` (`"red"` default, `"purple"`, `"gold"`), `theme` (`"dark"` for a `black-oak` slide).

Scale the slide with a CSS transform to fit its container. One accent colour per deck section.
