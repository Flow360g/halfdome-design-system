The four Half Dome values as finished tiles: **Constantly curious.** (`camas`), **Stay classy.** (`sequoia`), **Love mondays.** (`white-fir`) and **Blow things up.** (`white-fir`). Each pairs a hand gesture photographed on a brand shape with the value set in heavy Plus Jakarta Sans in the same colour, sentence case, ending in a full stop. HD_VALUES-20 to 23 include the words; the NOTEXT versions are the images alone for layouts that set the words live (use the `Statement` component). The coloured words are display-only artwork; never reuse purple or gold as text colour for information.
