The full illustrated icon library from the Asset Library (about 450 files, 160 icons). Each icon has a thick `black-oak` outline, a flat brand-colour fill and white highlights, some with a chalk stroke. File names read <Icon>-<Colour>, where Red = `sequoia`, Purple = `camas`, Green = `white-fir` (gold), White = `snow` fill for dark grounds and Black = single-ink. Numbered files (Award-117, Refresh-389, Trolley-385, Numbers-*) are extra variants kept as supplied.

Use one colourway per page, matched to the accent. Show icons at 48px or larger. Most icons are about 1042px square; Key-Result, Mobile and a few others sit on wide 6300 x 4200 canvases with the art centred, so crop or contain them. Platform icons (Facebook, Instagram, LinkedIn, TikTok, YouTube, Pinterest, Snapchat, Reddit, Twitter, Yahoo, GooglePlatform) are brand-styled illustrations, not the platforms' official logos; use the official logos from Publisher Logos when a partner requires it. Client-specific icons were left out on purpose, as were the United Airlines and nbn icons, which carry other companies' marks. `Org-Chart-Purple` comes from the library's 300ppi folder, where it is named Asset 1.
