The vertical "Whole Potential.™" lock-up: "Whole" in Libre Baskerville italic, "Potential." in roman, with the dome below. File names read Whole-Potential-<text colour>-<dome colour>. Use `Black-*` on light grounds and `White-*` (snow text) on dark grounds, matching the dome to the page accent. Run it up the edge of a layout with the dome sitting on the edge of the frame; always keep the full stop and ™. Transparent PNGs at 1500 x 4440. On slides it runs up the left edge of the cover, section dividers and the closing slide (about 300px high at 1920 x 1080), with its dome on the bottom edge.
