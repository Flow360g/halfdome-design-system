# Key assets

The assets most decks and pages need, by group, so you can pick the right file without browsing every folder. Paths are relative to the repository root.

When this repository is imported into a Claude design system, each asset is uploaded and gets an id; that system's copy of this file lists the id beside each name, and inside it an asset loads from `/_blob/<id>`.
